Pinpoint APM on Kubernetes

Chart 3.1.5 · Pinpoint 3.1.1 · Apache License 2.0

Helm charts for Pinpoint, the open-source APM for distributed tracing. The application chart deploys Pinpoint Web and Collector, either with bundled evaluation backends or connected to backends you operate.

Install

helm repo add pinpoint https://pinpoint-apm.github.io/pinpoint-kubernetes
helm repo update
helm upgrade --install pinpoint pinpoint/pinpoint \
  --version 3.1.5 --namespace pinpoint --create-namespace \
  --wait --timeout 20m
kubectl port-forward -n pinpoint service/pinpoint-web 8080:8080

Then open http://localhost:8080. The demo application sends traces automatically.

Choose a profile

ProfileValuesUse it for
EvaluationdefaultTrying Pinpoint with bundled HBase, MySQL, Redis, ZooKeeper, Kafka and Pinot.
Minimalvalues-minimal.yamlThe evaluation stack on one small node, such as kind or a laptop.
Productionvalues-production.yamlReplicated Web and Collector connected to independently managed backends.

Bundled backends are not meant for production. Read the production guide before going live.

Connect agents

Point Pinpoint agents at the Collector Service: gRPC port 9991 for agent and metadata, 9992 for statistics and 9993 for spans. See instrumenting applications for Kubernetes examples and external access.
