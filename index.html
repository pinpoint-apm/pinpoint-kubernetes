Pinpoint on Kubernetes.

Install Pinpoint APM with Helm. Start with the evaluation stack, or connect to your own backends for production.

Chart 3.1.1 Pinpoint 3.1.1

Quick install

Terminal
helm repo add pinpoint https://pinpoint-apm.github.io/pinpoint-kubernetes
helm repo update
helm upgrade --install pinpoint pinpoint/pinpoint \
  --version 3.1.1 --namespace pinpoint --create-namespace \
  --wait --timeout 20m

The default installation includes evaluation backends. For production, use the production guide.
